# Gannet 0.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use trivialpowers:subagent-driven-development (recommended) or trivialpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw the whole Gannet sidebar as one webview view: the workspace directories as a panel on top, the owners as the top-level rows below, no view header rows.

**Architecture:** `GannetTree` stays the model (its `getChildren`/`getTreeItem` are unchanged and keep their tests). A new
`rows.js` turns a node and its TreeItem into a plain row with a stable id; a new `sidebar.js` is the
WebviewViewProvider that answers the page's messages from that model; `media/page.js` is the page script, written so its
pure parts (escaping, row HTML, visible rows, keyboard moves) also load under Node for tests. Right-click uses VS Code's
`webview/context` menus, so the commands and their `when` conditions carry over with `webviewId` in place of `view`.

**Tech Stack:** VS Code extension API (WebviewViewProvider, `webview/context` menus, `data-vscode-context`), plain
CommonJS JavaScript, inline SVG, Node's `assert` tests (`npm run -s test:offline`).

**Spec:** `docs/notes/101-gannet.md`, section "## One sidebar, drawn as a webview (0.4.0)"; 0.3.0's section for
everything the tree holds.

The design holds every design decision; this plan holds build steps and code-level names only, and is deleted when
the work merges. If a decision changes during the build, change the design in the same commit.

## Global Constraints

- One view in the `gannet` container: `{ "type": "webview", "id": "gannet.main", "name": "" }`. **+ account** and **⟳** in its `view/title`.
- No new dependency: icons are inline SVG in the page; no icon font, no framework.
- Folders (remote `dir` entries, disk folders, checkout rows) have no icon; every file has the one generic file icon in the arrow's column.
- Colours and fonts from VS Code's CSS variables only (`--vscode-foreground`, `--vscode-descriptionForeground`, `--vscode-list-hoverBackground`, `--vscode-list-activeSelectionBackground`, `--vscode-list-activeSelectionForeground`, `--vscode-focusBorder`, `--vscode-charts-green`, `--vscode-widget-border`, `--vscode-font-family`, `--vscode-font-size`).
- Content Security Policy: `default-src 'none'; style-src ${cspSource} 'unsafe-inline'; script-src 'nonce-${nonce}'; img-src ${cspSource} data:`.
- Only ⟳ reads repo lists from GitHub again (0.3.0's `refresh` vs `redraw` stays).
- Version `0.4.0`; commits by Sean Ahn <seanahn@youriris.com>, ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; straight to `main`.

## Review Focus

1. A message naming a row id the extension no longer knows (clicked or expanded just before a refresh): ignored, no error toast, no crash.
2. Expanding a row whose children fail (signed out, rate limited): the error row replaces the spinner; the spinner never stays.
3. A file or repo name containing `<`, `&` or `"`: shown as text, never as markup, in labels, descriptions and tooltips.
4. A remembered expanded id that no longer exists after a reload (repo deleted, account hidden): ignored, no request loop.
5. Two children of one parent whose keys collide (two info rows, a repo listed in Recent and All repos under one owner): every row id is unique.

### Task 1: Rows from the model

**Files:**
- Create: `src/rows.js`
- Test: `test/rows.test.js`
- Modify: `package.json` (`test:offline` runs the new test)

**Interfaces:**
- Consumes: `GannetTree#getTreeItem(node)`, `getChildren(node)` (unchanged).
- Produces:
  - `nodeKey(node): string` — `owner` → `o:<login>:<owner>` lowercased; `group` → `all`; `repo` → `r:<fullName lowercased>`; `checkout` → `c:<path>`; `entry` → `e:<entry.path>`; `disk` → `d:<basename>`; `info` → `i:<label>`; `error` → `x`.
  - `childIds(parentId: string|null, nodes): string[]` — `parentId ? parentId + '/' + key : key`, with a `#2`, `#3`… suffix on a repeated key.
  - `toRow(item: TreeItem, id: string): Row` where `Row = { id, label, description, tooltip, icon: null | { id, color }, hasChildren, expanded, contextValue, clickable }` — `icon` is `null` for `ThemeIcon.Folder` and for no icon, `{ id: 'file' }` for `ThemeIcon.File`, else `{ id: iconPath.id, color: iconPath.color && iconPath.color.id }`; `hasChildren` = collapsibleState ≠ None; `expanded` = collapsibleState is Expanded; `clickable` = `!!item.command`; `tooltip` a string or `''`.
  - `createRowStore(tree)` → `{ root(): Promise<Row[]>, children(id): Promise<Row[] | null>, node(id): node | undefined, item(id): TreeItem | undefined, clear() }`. `children` returns `null` for an unknown id. It keeps `id → node` for every row it has handed out since the last `clear()`.

### Task 2: The page

**Files:**
- Create: `media/page.js`, `src/page.js`
- Test: `test/page.test.js` (add to `test:offline`)

**Interfaces:**
- Consumes: `Row` from Task 1.
- Produces:
  - `media/page.js` — in the browser it runs the page; under Node (`typeof module !== 'undefined'`) it exports the pure parts without touching the DOM:
    - `esc(s): string` — escapes `& < > " '`.
    - `ICONS: { [id]: svgString }` for `file, organization, account, github-alt, warning, file-submodule, repo, chevron, cloud, folder-opened, close, add, loading`; an unknown id draws nothing.
    - `rowHtml(row, depth, { open, loading, focused }): string` — `<div class="row" role="treeitem" data-id=… aria-expanded=… data-vscode-context='{"webviewSection":"row","viewItem":…,"nodeId":…,"preventDefaultContextMenuItems":true}' title=…>`, indent `depth * 8 + 4` px, a 16 px twistie column (chevron when `hasChildren`, the icon there when `!hasChildren`), then for rows with children their icon (none for folders), label, description in `.desc`; a hover-only cloud button `data-act="checkout"` when `contextValue === 'repo-remote'`; a spinner instead of the chevron when `loading`.
    - `workspacesHtml(items: {path, label, missing}[]): string` — one `.ws` row each (label, `Missing` in `.desc` when missing, hover buttons `data-act="reveal"` (not when missing) and `data-act="remove"`), then a `.ws.add` row "Add folder…".
    - `visible(rootIds, kids: Map<id, Row[]>, open: Set<id>): {row, depth}[]` — depth-first, children of open rows that have arrived.
    - `move(key, focusId, list, open): { focus?, expand?, collapse?, activate? }` — ArrowDown/ArrowUp next/previous; ArrowRight on a closed parent `expand`, on an open one focus its first child; ArrowLeft on an open parent `collapse`, else focus its parent; Enter/Space `activate`.
  - The browser part: posts `ready` on load; keeps `{ open: {id: bool} }` in `vscode.setState`; a row's default openness is `row.expanded` unless the state says otherwise; on `rows` it stores children and asks `expand` for any open child it has no rows for; on `reset` it drops all children and re-asks the root; click on a row: toggles it if it has children and posts `click` if `clickable`; hover buttons post their `act`; keyboard via `move`.
  - `src/page.js`: `pageHtml({ cspSource, scriptUri, nonce }): string` — the HTML shell with the CSP from Global Constraints, the CSS, `<div id="ws"></div><hr><div id="tree" role="tree" tabindex="0"></div>`, and `<script nonce=… src=scriptUri>`.

### Task 3: The webview provider

**Files:**
- Create: `src/sidebar.js`
- Modify: `test/stubs.js` (a fake `registerWebviewViewProvider` and webview view)
- Test: `test/sidebar.test.js` (add to `test:offline`)

**Interfaces:**
- Consumes: `createRowStore(tree)` (Task 1), `pageHtml` (Task 2), `createWorkspaces` list, `W.exists`, `W.tilde`.
- Produces: `class GannetSidebar { constructor({ vscode, tree, workspaces, home, extensionUri }); resolveWebviewView(view); refreshWorkspaces(); resolve(arg): node | undefined }`, `GannetSidebar.viewType = 'gannet.main'`.
  - `resolveWebviewView`: `view.webview.options = { enableScripts: true, localResourceRoots: [media] }`; html from `pageHtml` with a fresh nonce and `asWebviewUri(media/page.js)`; listens to messages.
  - Messages in → out:
    - `ready` → `{type:'workspaces', items}` then `{type:'rows', parent:null, rows: await store.root()}`;
    - `expand {id}` → `{type:'rows', parent:id, rows}`, nothing when `children` gives `null`;
    - `click {id}` → `executeCommand(item.command.command, ...item.command.arguments)`;
    - `act {act:'checkout', id}` → `executeCommand('gannet.checkout', node)`;
    - `ws {act:'add'}` → `gannet.addWorkspace`; `ws {act:'remove'|'reveal', path}` → `gannet.removeWorkspace` / `gannet.revealWorkspace` with `{ path }`.
    - Unknown ids and unknown messages are ignored.
  - `tree.onDidChangeTreeData` → `store.clear()` and `{type:'reset'}`; `refreshWorkspaces()` posts `workspaces`.
  - `resolve(arg)`: a node (has `kind`) as is; `{nodeId}` → `store.node(nodeId)`; else `undefined`.
  - `items`: `workspaces.list().map((p) => ({ path: p, label: W.tilde(p, home), missing: !W.exists(p) }))`.
